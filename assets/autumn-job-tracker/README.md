# 求职工作台 Edge 扩展

这是一个可直接加载到 Microsoft Edge 的本地扩展。它会在你登录招聘网站后识别投递记录，也可以从已登录的网页版邮箱中识别秋招通知，再按照你设置的每日时间复查。

## 安装到 Edge

1. 在 Edge 地址栏输入 `edge://extensions` 并打开；
2. 打开“开发人员模式”；
3. 点击“加载解压缩的扩展”；
4. 选择整个 `autumn-job-tracker` 文件夹；
5. 在扩展菜单中把“求职工作台”固定到工具栏。

更新现有版本时，请回到 `edge://extensions`，在“求职工作台”卡片上点击“重新加载”。不要只选择 `manifest.json`。

## 第一次使用

1. 第一次打开完整面板时，填写姓名、手机号和 1–5 个招聘通知邮箱；
2. 正常登录招聘网站，打开“我的申请”“投递记录”“候选人中心”或具体申请详情页；
3. 点击扩展图标后，扩展会把识别到的岗位信息预填到表单，企业名字由你手动填写并确认保存；
4. 如果页面信息不完整，扩展会保留地址栏中的完整网页链接，缺少的岗位名称、地点和投递日期也由你补充；
5. 在 Edge 中登录一次常用的网页版邮箱；扩展会直接使用首次填写的邮箱列表进行后台检查，不需要再到邮箱页面点击扩展；
6. 打开完整面板，可以查看记录、立即刷新、修改每日抓取时间和查看秋招邮件记录。

## 记录字段

进度台只保存以下申请信息：

- 岗位名称；
- 企业名字（位于岗位名称之后，仅允许手动填写）；
- 工作地点；
- 投递日期；
- 当前进度；
- 未完成的测试或面试及截止时间；
- 查询网站（始终取自 Edge 地址栏中的当前完整网址）；
- 登录状态和最近检查时间。

企业名字使用独立的手动存储字段，与网页抓取字段完全分离。网页标题、站点名称、抓取结果和邮件中的单位名称均不能写入或覆盖它。因此 `https://babycare.zhiye.com/personal/deliveryRecord` 的页面标题“今天你投简历了吗？”不会成为企业名字；升级时也会删除旧的网页同名字段并清理这一错误标题。抓取时企业名字输入框保持空白，必须由你填写，之后也可以在进度台的编辑弹窗中手动修改。

## 抓取和刷新规则

- 投递页信息完整时会预填岗位、地点、日期、进度和当前网页链接，并打开表单要求你手动填写企业名字；
- 同一页面识别到多条投递时，会逐条打开表单，让你分别填写企业名字；
- 信息不完整时会保留当前地址栏链接，并在表单中提示你补充缺少内容；
- 企业名字、岗位名称、工作地点和投递日期首次保存后会锁定，立即刷新和定时刷新只更新进度、截止时间、登录状态及更新时间；
- 只有你主动打开编辑表单并保存，才会修改企业名字、岗位名称、工作地点或投递日期；
- 单独打开或刷新招聘网站、邮箱网站时，扩展保持静默，不会自动扫描、抓取或保存；
- 自动抓取、立即刷新、定时刷新和邮件更新都不会写入或覆盖企业名字；
- 后台刷新页不会触发新增记录，避免刷新时重复新增或覆盖现有记录；
- 编辑弹窗不会因为点击弹窗外、输入内容或选择下拉项而关闭，只会在保存、取消、关闭或删除时退出；
- 查询页面可正常读取时显示绿色圆灯；登录失效、验证码或页面异常时显示红色感叹号并提醒。
- 工作台顶部会汇总下一步行动、最近截止时间和待完成事项，方便优先安排测评、笔试和面试。
- 左侧小狗助手会按早中晚切换工作、吃饭和睡觉状态；有新进程时显示惊讶和感叹号，需要重新登录时显示疑惑和问号。点击小狗可打开通知详情。

## 邮箱抓取

- 支持在已登录的 QQ、163、Gmail、Outlook 等网页版邮箱中识别当前已加载的招聘、测评、笔试、面试、拒信和 Offer 邮件；
- QQ、163、126、Gmail、Outlook 等常见邮箱会直接由首次填写的邮箱地址生成检查入口，不需要先打开邮箱页面点击扩展；
- 企业或学校自建邮箱如果无法自动识别入口，仍可在登录网页版邮箱后抓取一次，以登记它的实际入口；
- 每次立即刷新或定时刷新时，会在每个已登记的网页版邮箱中按你手填的企业名字执行搜索；
- 点击“立即刷新进度”时，扩展会自动打开第一个已登记邮箱的收件箱并执行检查；定时检查会在后台静默打开，不需要你先手动进入邮箱页面。
- 搜索不限制已读或未读，但只检查收件箱，不再搜索垃圾邮件或广告／推广目录；
- 每个企业在每个邮箱的一次刷新中只在“全文搜索／搜索邮件”框提交一次收件箱搜索；即使输入框和放大镜按钮不在同一层，也会自动点击该搜索按钮一次。不会使用 AI 搜索、联系人搜索或其他搜索入口，打开邮件详情并返回后也不再重复搜索；
- 邮箱搜索和结果读取会检查网页邮箱的内嵌页面；QQ、163 等把邮件列表放在内嵌页面中的邮箱不再只扫描最外层空页面；
- 搜索结果只要标题、发件人或摘要中包含完整企业名字就会被抓取，不再要求邮件同时出现“招聘”“面试”等额外关键词；
- 普通 `div` 邮件卡片也会被识别，避免邮箱页面能看到正确结果但未写入面板；
- 找到匹配邮件后会逐封打开详情页，从完整标题、发件人、正文与时间中提取记录，再返回搜索结果继续处理下一封；
- 每封搜索结果都会保存稳定标识；已收录、待确认、已取消或已删除的邮件会在打开详情前跳过，后续刷新不会重复收录；
- 搜索到的邮件优先按企业名字匹配投递记录；同一企业有多个岗位时，再用岗位名称区分；
- 邮件只使用企业名字进行查找和匹配，不会改写手填的企业名字；
- 无法唯一匹配的邮件进入面板上方独立的“待确认邮件”区域，不会提前出现在秋招邮件记录中；
- 点击“确认并加入邮件记录”后，该邮件会进入“秋招邮件记录”；点击“取消”后会移除并记住忽略，避免以后重复出现；
- “秋招邮件记录”支持单封删除、逐封多选、全选和批量删除；数字编号以及缺少编号或签名的旧邮件也可以批量删除，确认删除后会从当前设备移除并记住忽略，后续刷新不会重新收录同一封邮件；
- 点击“立即刷新进度”结束后，面板会强制重新读取邮件记录，并在提示中显示本次收录数量与待确认数量；
- 面板会记录邮箱来源、邮件所在位置、邮件标题、短摘要、匹配企业／岗位、识别阶段、截止时间和最近抓取时间。

## 定时与通知

- 默认每天本地时间 12:00 和 18:00 自动检查，可在进度台中改成 1–5 个自定义时间；保存后会立即重建定时任务并显示下一次运行时间；
- 点击“立即刷新进度”可随时手动检查；
- 进入下一阶段时提示“恭喜您进入下一个阶段，目前进行到 XX 阶段”；
- 未通过时提示“很遗憾这个不是你最好的选择”；
- 新状态会显示系统通知，并在 Edge 扩展图标保留未读数字；
- Edge 关闭或电脑休眠时无法准时后台检查，下次启动后会补查最近一次。

## 登录、验证码与隐私

扩展复用当前 Edge 配置中已有的招聘网站和网页版邮箱登录状态，不读取、复制或上传 Cookie、账号密码或短信验证码。网站要求重新验证时，仍需你本人完成一次验证。

数据只保存在当前 Edge 扩展的本地存储中，没有上传到外部分析服务。当前版本尚未接入端到端加密云同步，因此手机端不能同步查看这批数据，也不要在公共电脑或不受信任的 Edge 配置中安装。

## 文件说明

- `manifest.json`：Edge 扩展配置；
- `background.js`：定时任务、进度更新与通知；
- `extractor.js`：招聘页面与秋招邮件识别规则；
- `content.js`：登录后页面扫描；
- `popup.html`：工具栏扩展弹窗；
- `index.html`：完整投递面板。
